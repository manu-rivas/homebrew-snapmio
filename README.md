# Homebrew tap for Snapmio

[Snapmio](https://snapmio.app/) is a native macOS app to annotate, redact and copy screenshots right after you take them.

```sh
brew trust manu-rivas/snapmio   # Homebrew asks you to trust third-party taps once
brew install --cask manu-rivas/snapmio/snapmio
```

Snapmio updates itself (Sparkle); this cask is updated automatically with every release.
